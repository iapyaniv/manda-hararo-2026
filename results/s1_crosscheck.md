# Sentinel-1 cross-check of the NISAR-derived dike model

- LiCSAR 014A_07688_131313 pair 20260712_20260718; 40371 compared pixels (cc>0.25, |pred|>0.5 cm, 3× subsample)
- regression slope obs-vs-model: -0.918 ⇒ LiCSAR unw sign convention opposite to the model convention (applied factor -1)
- **correlation r = 0.974**, amplitude ratio |slope| = 0.92
- **RMS residual = 1.8 cm** against a model fitted to NISAR only

The observed and predicted fields have the correlation, amplitude ratio, and
RMS residual reported above. Residuals are concentrated near the axis, where the
uniform-opening model does not represent graben faulting.
